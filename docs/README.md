# DecisionFlow documentation

This directory contains concise, durable context for contributors and coding
agents.

- [`PROJECT_CONTEXT.md`](PROJECT_CONTEXT.md): current system map, capabilities,
  boundaries, and verification commands.
- [`decisions/`](decisions/README.md): architectural decision records for
  choices that should remain understandable after the originating task or chat
  is gone.

Detailed backend API, environment, deployment, and operational documentation
lives in `decisionflow-backend/README.md`. Frontend setup and route information
lives in `decisionflow-web-app/README.md`.

The root `AGENTS.md` requires documentation to be reviewed whenever behavior
changes.
